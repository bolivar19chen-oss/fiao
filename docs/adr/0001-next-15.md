# ADR 0001 - Next.js 15 en lugar de Next.js 14

Fecha: 2026-10-15. Estado: aceptado.

## Contexto

El plan fijaba Next.js 14. `pnpm audit` sobre 14.2.35, la ultima version 14, reporta
vulnerabilidades criticas sin parche en la rama 14:

- GHSA-p293-qw3h-jr36: ejecucion remota de codigo sin autenticacion en servidores Windows.
- GHSA-2xp9-vwfh-vxw4: ejecucion remota de codigo en la Image Optimization API con AVIF.

Ambas estan corregidas desde 15.5.24.

## Decision

Usar Next.js 15.5.x (15.5.28 al momento) con React 19, que es la version de React que
Next 15 usa en el App Router. `eslint-config-next` sigue la misma version que `next`.

No se salta a Next 16: no hace falta para cerrar las vulnerabilidades y seria un cambio
mayor sin necesidad.

## Consecuencias

- `cookies()`, `headers()` y `params` pasan a ser asincronos. El codigo actual no los usa;
  al usarlos (auth, Fase 2) hay que hacer `await`.
- `next lint` esta deprecado en 15.5 y desaparece en 16. Migrar a la CLI de ESLint cuando
  se suba a 16.
- cobe, Recharts y lucide-react ya declaran soporte para React 19.
